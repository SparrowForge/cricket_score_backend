WHAT CHANGED:
─────────────

1. CONTRIBUTION POINT (NEW)
   Formula: player_runs / overs_per_innings

   Examples:
   ├─ T20 (20 overs):   20 runs = 1.0 point,   40 runs = 2.0 points,   60 runs = 3.0 points
   └─ ODI (50 overs):   50 runs = 1.0 point,  100 runs = 2.0 points,  150 runs = 3.0 points

   • Rewards significant batting contributions
   • Uncapped — reflects actual contribution ratio
   • Fair across all formats

2. BATTING MILESTONE THRESHOLDS
   OLD (absolute):  4×O, 6×O, 8×O, 10×O

   NEW (format-dependent):
   ├─ 1-20 overs:   1.5×O, 2×O, 2.5×O, 3×O
   └─ 21+ overs:    1×O, 1.4×O, 1.6×O, 2×O

2. WINNING TEAM BONUS
   OLD: +2 points for every team member + 1.1× multiplier
   NEW: Only 1.1× multiplier (no flat +2)

EXAMPLES:
─────────

T20 Match (20 overs):
  • 30 runs = +4 (1.5×20)     ← was 4×20, not reached
  • 40 runs = +8 (2×20)        ← old was 4×20
  • 50 runs = +12 (2.5×20)     ← old was 6×20
  • 60 runs = +16 (3×20)       ← old was 8×20

ODI Match (50 overs):
  • 50 runs = +4 (1×50)        ← was 4×50, not reached
  • 70 runs = +8 (1.4×50)      ← old was 4×50
  • 80 runs = +12 (1.6×50)     ← old was 6×50
  • 100 runs = +16 (2×50)      ← old was 10×50
